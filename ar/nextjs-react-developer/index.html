مطور Next.js وReact يبني الـ API أيضًا.

أبني واجهات Next.js وReact فوق أنظمة خلفية أبنيها بنفسي، فتُصمَّم الواجهة والـ API معًا. عملي الحالي هو تطبيق الويب لمنصة كيلد على Next.js 16 وReact 19: مناطق للمدير والتاجر والفرع والوكيل والعميل، ثنائي اللغة بالكامل مع دعم RTL والوضع الداكن.
