أنا بلال أرشد، مطور Laravel أول بخبرة تزيد عن 8 سنوات في PHP. أبني أنظمة Laravel ولوحات تحكم وواجهات REST API تعمل في بيئة الإنتاج تحت ضغط حقيقي: منصة بث تخدم أكثر من 2.4 مليون مستخدم، ونظام فوترة آلي لشركة لوجستية، وأنظمة نقاط بيع وتقسيط، ومنتجات مُحسّنة لمحركات البحث بأكثر من 20 لغة.

01 الخدمة

ماذا أبني

01

واجهات REST API بـ Laravel

واجهات موثّقة ومُرقّمة الإصدارات لتطبيقات الويب والجوال، مع صلاحيات وتحقق من المدخلات وتحديد معدل الطلبات.

02

تطبيقات Laravel مع Vue وInertia

لوحات تحكم سريعة بـ Inertia.js وVue مع العرض من جهة الخادم عند الحاجة لمحركات البحث، أو Blade وAlpine.js للمشاريع الأخف.

03

تحسين الأداء

تحسين الاستعلامات والفهارس والتخزين المؤقت بـ Redis. إحدى المنصات انخفض زمن تحميلها من ثانيتين إلى 120 جزءًا من الثانية.

04

الطوابير والمهام الخلفية

طوابير Laravel لمعالجة الوسائط والاستيراد والبريد والفوترة المجدولة.

05

البحث

Laravel Scout مع Meilisearch أو Algolia أو Elasticsearch لبحث سريع في الكتالوجات.

06

التكاملات

Xero وStripe وPayPal وميسر وهيئة الزكاة (فاتورة) وTMDB وOpenAI والرسائل النصية والإشعارات.
