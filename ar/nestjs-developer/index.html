Node.js · NestJS · TypeScript · Prisma

مطور NestJS لأنظمة تتعامل مع المال.

أقود تطوير الواجهة الخلفية لمنصة كيلد (Keeld)، وهي سوق إلكتروني متعدد البائعين ومنصة مدفوعات ثنائية اللغة للتجار في السعودية، مبنية على NestJS وPrisma وPostgreSQL. تضم 23 وحدة و119 نموذج بيانات تغطي الطلبات والمحافظ والتسويات والاسترجاع والعقود والعروض والدعم والعمولات، وتخدم تطبيق ويب بـ Next.js وتطبيق جوال بـ Flutter.

01 الخدمة

ماذا أبني

01

بنية NestJS معيارية

وحدات ومحارس واعتراضات وتحقق من البيانات تبقى واضحة مع نمو المشروع لأكثر من 20 وحدة.

02

نماذج بيانات Prisma وPostgreSQL

مخططات وترحيلات ومعاملات وفهارس مصممة للدقة المالية وسرعة القوائم.

03

المدفوعات والتسويات

مدفوعات ميسر وwebhooks ومطابقة واسترجاع ومحافظ التجار ومحرك دفعات أسبوعي مع كشوفات Excel وPDF.

04

واجهات API لتطبيقات الجوال

واجهات REST لتطبيقات Flutter تعيد استخدام منطق الدفع والحسابات من الويب، مع ترقيم صفحات وفلاتر من جهة الخادم.

05

الصلاحيات والتدقيق والأمان

صلاحيات حسب الدور، وسجل تدقيق للإجراءات الحساسة، وحماية المستندات الخاصة، وقواعد إيقاف التجار.

06

النشر في الإنتاج

Docker Compose خلف Caddy أو Nginx مع نسخ احتياطي لقاعدة البيانات وترحيلات.
